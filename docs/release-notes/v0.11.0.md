BOUND 0.11.0 brings **BoundHash**, BOUND's own proof of work, in place of Bitcoin's SHA-256d, and
**starts the testnet over** on it. Bitcoin's mining machines can't mine BOUND any more: it takes a
CPU's memory and multiplications ([how it works](https://github.com/Sonic-Bound/Bound/blob/main/docs/boundhash.md)).

It runs the **testnet**, whose coins have no value. Mainnet hasn't launched yet: `--mainnet` runs a
preview chain that will be thrown away.

## Downloads

| File | For |
|---|---|
| `bound-0.11.0-win64.zip` | Windows 10 or 11, 64-bit: the wallet app (`bound-qt.exe`) and the command-line programs, with everything they need |
| `bound-0.11.0-x86_64-linux-gnu.tar.gz` | Linux x86-64 with glibc 2.35 or newer (Ubuntu 22.04, Debian 12, Fedora 36 or later): `boundd`, `bound-cli`, `bound-explorer`, `bound-seeder`, systemd units and `bound-server` |
| `bound-0.11.0-aarch64-linux-gnu.tar.gz` | the same for 64-bit ARM with glibc 2.39 or newer |
| `SHA256SUMS` | the SHA-256 of each file |

**Windows:** unzip, then double-click `bound-qt.exe`. The programs aren't code-signed yet, so Windows
may say *"Windows protected your PC"*: check the download (below), then choose *More info* and
*Run anyway*.

**Linux:** unpack, then `bin/boundd node`.

## Check the download

Compare the file's SHA-256 with `SHA256SUMS` (`Get-FileHash <file>` on Windows,
`sha256sum --ignore-missing -c SHA256SUMS` on Linux). GitHub also attests every file: it was built
by this repository's release workflow from the `v0.11.0` tag. With the [GitHub CLI](https://cli.github.com):

    gh attestation verify bound-0.11.0-win64.zip --repo Sonic-Bound/Bound

## What's new since 0.10.0

- **BoundHash.** A memory-hard proof of work built from SHA-256 and Argon2's mixing: half a megabyte
  of memory and about a millisecond per hash. Block ids are still SHA-256d, so they no longer start
  with zeros; the proof of work is a separate number.
- **The testnet starts over** from its 01/Nov/2026 genesis, mined again with BoundHash, with a new
  network magic: 0.10.0 nodes and 0.11.0 nodes don't talk to each other.
- **Mainnet's difficulty 1 is 2^22 BoundHash hashes,** about a quarter of an hour for a PC on every
  core, as Bitcoin's difficulty 1 was.
- **Mining:** hash rates are now in hashes a second, not millions; a 6-core PC does a few thousand.
- **`boundd genesis`** mines a genesis on every core and prints it, the same block every time.

## Upgrading

Stop the old wallet app or node, then start the new one. It finds the old testnet chain, which can't
continue, and moves it with its wallet to `old-chain-0000a7ba…` inside the data directory
(`%APPDATA%\BOUND\testnet`, `~/.bound/testnet`); then it syncs the new testnet from the start. The
wallet app's Overview offers to create a new wallet: the old one's coins were on the old chain. On a server,
`sudo bound-server install` does the same.

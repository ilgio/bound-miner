BOUND 1.1.0 brings an **installer for Windows** and a better **wallet app**: a fresh look, a QR code to
receive, contacts, a Max button and fees as Slow, Normal or Fast. Mainnet's rules don't change:
1.0.0 and 1.1.0 nodes run the same chain.

## Downloads

| File | For |
|---|---|
| `bound-1.1.0-win64-setup.exe` | **Windows 10 or 11, 64-bit: the installer.** BOUND in the Start menu, an uninstaller |
| `bound-1.1.0-win64.zip` | the same programs in a folder, to run without installing (`bound-qt.exe`) |
| `bound-1.1.0-x86_64-linux-gnu.tar.gz` | Linux x86-64 with glibc 2.35 or newer: `boundd`, `bound-cli`, `bound-explorer`, `bound-seeder`, systemd units and `bound-server` |
| `bound-1.1.0-aarch64-linux-gnu.tar.gz` | the same for 64-bit ARM with glibc 2.39 or newer |
| `SHA256SUMS` | the SHA-256 of each file |

**Windows:** run the installer, then start **BOUND** from the Start menu. The programs aren't
code-signed yet, so Windows may say *"Windows protected your PC"*: check the download (below), then
choose *More info* and *Run anyway*.

**Linux:** unpack, then `bin/boundd node`.

## Check the download

Compare the file's SHA-256 with `SHA256SUMS` (`Get-FileHash <file>` on Windows,
`sha256sum --ignore-missing -c SHA256SUMS` on Linux). GitHub also attests every file: it was built
by this repository's release workflow from the `v1.1.0` tag. With the [GitHub CLI](https://cli.github.com):

    gh attestation verify bound-1.1.0-win64-setup.exe --repo Sonic-Bound/Bound

## What's new since 1.0.0

- **The installer.** One file installs BOUND for everyone (with admin rights) or just you, adds it to
  the Start menu, with the testnet beside it, and can be uninstalled from Windows' settings.
  Uninstalling keeps the chain and the wallet in `%APPDATA%\BOUND`.
- **A fresh look:** icons, Send and Receive under the balance, recent payments you can click for
  their details, amounts without needless zeros, and light or dark as Windows switches.
- **Receive** shows your address as a QR code, and can ask for an amount with a payment link
  (`bound:<address>?amount=1.5`). It also says why there are new addresses: privacy. Fixed: the
  Copy button didn't work for mainnet addresses.
- **Contacts:** save names for the addresses you pay, pick them on Send, see them in your history.
- **Easier sending:** paste a payment link to fill the address and amount; **Max** sends everything,
  the fee taken out; the fee as **Slow**, **Normal** or **Fast**, with what it costs.
- **Transaction details** show the contact and memo, and open the transaction on the explorer.
  Transactions can be searched.
- **`sendall`**: a new RPC that empties the wallet to an address, for `bound-cli` too.

## Upgrading from 1.0.0

Close the wallet app, then run the installer, or unzip the new folder. The chain and the wallet stay
where they were. On a server: `sudo bound-server install`.

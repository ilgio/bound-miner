BOUND 1.0.0 launches **mainnet**: a proof-of-work coin written from scratch in C++20, started the
way Bitcoin was. No premine: the genesis block quotes a headline from launch day, its reward can
never be spent, and block 1 is open to anyone who runs this release.

    Genesis  be44789ea517f65d9c690a4690e45ac5189777ff1d34b1ced3d73c3c20674bad
    Message  "BOUND 16/Nov/2026 12 NBFCs lose over Rs 65 crore in three months to cyber fraud in Delhi-NCR"
    Time     2026-11-16 10:24:21 UTC

The message is a headline from that day's front page of *The Indian Express*.

## The coin

| | |
|---|---|
| Blocks | every 10 minutes on average |
| Reward | 50 BOUND, halving every 210,000 blocks (about 4 years) |
| Supply | 20,999,999.9769 BOUND, Bitcoin's exact schedule |
| Proof of work | [BoundHash](https://github.com/Sonic-Bound/Bound/blob/main/docs/boundhash.md), BOUND's own: memory-hard, CPU-mined, out of reach of Bitcoin's mining machines |
| Difficulty | from difficulty 1 (a PC's quarter of an hour), adjusted every block (ASERT) |
| Addresses | start with `B` |
| Premine | none |

## Start mining

**Windows:** unzip `bound-1.0.0-win64.zip`, double-click `bound-qt.exe`, open *Mining* and press
*Start mining*. It's a full node with a wallet: it finds the network by itself, and mined coins
show up in the wallet, spendable 100 blocks later. The programs aren't code-signed yet, so Windows
may say *"Windows protected your PC"*: check the download (below), then choose *More info* and
*Run anyway*.

**Linux:** unpack, then `bin/boundd node --mine <your address>` (make one with the wallet app, or
`bin/bound-cli getnewaddress` against a running node).

The explorer is at [explorer.bound.sarl](https://explorer.bound.sarl).

## Check the download

Compare the file's SHA-256 with `SHA256SUMS` (`Get-FileHash <file>` on Windows,
`sha256sum --ignore-missing -c SHA256SUMS` on Linux). GitHub also attests every file: it was built
by this repository's release workflow from the `v1.0.0` tag. With the [GitHub CLI](https://cli.github.com):

    gh attestation verify bound-1.0.0-win64.zip --repo Sonic-Bound/Bound

Anyone can check the genesis too: it mines again from its message and time, to the same block.

    boundd --mainnet genesis "BOUND 16/Nov/2026 12 NBFCs lose over Rs 65 crore in three months to cyber fraud in Delhi-NCR" 1794824661

## What's new since 0.11.0

- **Mainnet's real genesis,** mined on launch day, in place of the preview's.
- **The wallet's backup is 24 words,** as in Bitcoin wallets, instead of 64 hex digits. A wallet
  from before shows its seed as words now (*File > Back up the 24 words*); restoring takes the words
  or an old backup's hex. Only BOUND's wallet restores BOUND coins from them: Trust Wallet or
  MetaMask would open an empty wallet of their own.
- **Mainnet is the default network.** `--testnet` joins the testnet, which keeps running beside it
  (its explorer is now [testnet-explorer.bound.sarl](https://testnet-explorer.bound.sarl)).

## Upgrading from 0.11.0

Stop the old wallet app or node, then start the new one. The testnet chain and wallet stay where they
were (`%APPDATA%\BOUND\testnet`, `~/.bound/testnet`); start with `--testnet` to keep using them.
Mainnet's are new (`%APPDATA%\BOUND\mainnet`). A chain from an earlier `--mainnet` preview is moved
aside by itself (`old-chain-…`): nothing mined on it is on the real chain.
